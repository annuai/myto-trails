# Myto Dash

A minimal Android home-screen launcher for motorcycle and car head units (the
aftermarket "Android radio" units, not Android Auto), in the Myto design system.
It is a fork of [Dashline](https://github.com/metehankaygsz/dashline) by Metehan
Kaygısız, restyled and trimmed: one screen with a clock and weather panel, a
media card, a second card (phone, app shortcuts or hosted widgets, including
Myto's Quick actions widget) and a tab bar.

Native Kotlin with classic Views, not Expo: a launcher has to register as HOME,
host other apps' widgets and read the playing media session, and it has to run on
slow units without Play Services. Package `com.myto.dash`, minSdk 21.

## Build

Needs the Android SDK and JDK 21 (Android Studio's bundled one works).

```bash
JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew :app:assembleDebug :app:lintDebug
```

`./gradlew :app:installDebug` installs on a connected phone or unit. Release
builds (`assembleRelease`) are minified and signed from `keystore.properties`
(gitignored) or the `KEYSTORE_*` environment variables; without them they build unsigned.

## Design system

Myto Dash follows the phone app's tokens ([docs/design-tokens.md](../../docs/design-tokens.md)),
copied into Android resources because Gradle cannot read `packages/tokens`:

| Myto source | Here |
|---|---|
| `light` / `dark` palettes (`packages/tokens/src/mobile.ts`) | `res/values/colors.xml`, `res/values-night/colors.xml` |
| `space`, `radius`, `size`, `type` (`apps/mobile/src/theme/tokens.ts`) | `res/values/tokens.xml`, text styles in `res/values/styles.xml` |
| Geist, Geist Mono, Michroma | `res/font/` (from `@expo-google-fonts`, OFL, see `licenses/`) |
| Lucide icons | `res/drawable/ic_*.xml`, generated by `node tools/lucide-to-vector.mjs ../../node_modules/lucide-react-native/dist/esm/icons` |

Change a colour or size in the phone app's tokens and copy it here by hand.
Choices specific to Dash: no shadows anywhere (surfaces part by colour); the
clock is Michroma; numbers are Geist Mono; the media card has the sky Dash tint
and the phone card the sand tint; a card holding only Myto widgets drops its
padding and tint so the widget fills it; Settings is a gear in the top bar, and
its bottom tab is off by default.

Dropped from Dashline: the self-updater and KitKat build, colour-gradient themes,
the in-app language picker and its translations (it follows the system language).
